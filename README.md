# Task Manager (Python console application):
A very simple console application to manage daily tasks, built for the
*Collaborative Tools with Git / GitHub* course (Year 1, Semester 1) - Part 1.

**Team:** Riadh Bouzaiene 1_GLSI_A

## Features
- **1 - Add a task**: asks for a title, rejects empty input, adds the task to the list.
- **2 - Display tasks**: shows all tasks with their numbers, or a message if the list is empty.
- **3 - Search for a task**: asks for a keyword and shows the tasks whose titles contain it (not case-sensitive).
- **0 - Exit**: closes the program. Any other option displays an error message.

Tasks are kept in memory only (a Python list), so they are lost when the program closes.

## How to run
1. Open the project folder in Visual Studio Code (**File > Open Folder**).
2. Open the file `main.py`.
3. Click the **Run Python File** button (the triangle at the top right of the editor).
4. Use the menu in the terminal: type `1`, `2`, `3` or `0` and press Enter.
